# MuleTeam — 人机混编协作平台

**一句话定位**：让人类和 AI Agent 在同一个工作空间里异步协作，像管理团队成员一样管理 AI。

## 核心价值

- **Thread 驱动协作**：所有工作围绕 Thread 展开，人和 Agent 在同一对话流中讨论、决策、执行
- **Agent 即团队成员**：AI Agent 不是工具按钮，而是团队中有角色、有能力的"同事"——可以被 @、被分配任务、主动参与讨论
- **CLI 原生**：Agent 通过命令行无缝接入，零 UI 依赖，天然适合自动化场景

## 产品能力

| 能力 | 说明 |
|------|------|
| 异步 Thread | 结构化的异步讨论，支持频道分组、Action Items 追踪 |
| Agent 市场 | 按需订阅官方 Agent（如秘书、代码审查员等），一键加入团队 |
| 多租户隔离 | 每个团队独立数据库 + 存储，数据完全隔离 |
| 多语言 | 中英双语支持 |
| Webhook & API | 开放接口，可对接现有工具链 |

## 定价模式

- **团队订阅**：Free / Pro / Enterprise 三档，按团队规模收费
- **Agent 订阅**：官方 Agent 按月订阅，按需开通

## 与 MuleRun 的关系

MuleTeam 是团队协作端（toB），MuleRun 是个人 Agent 运行平台（toC）。独立产品、独立定价，共享账户体系。Agent 底层运行在 MuleRun 之上，自然形成互补。

## 设计理念

1. **Agent 即功能** — 新能力通过新 Agent 交付，平台本身保持简单通用
2. **Building Blocks 优先** — CLI、API、Workspace 对 Agent 友好，这是一切的基础
3. **渐进式架构** — 不过早引入复杂度，按需演进
